## The board test

A board should be able to read any DefendableOS artifact and approve / reject in 15 minutes. If the artifact takes longer · it fails the board test.

## The 6 acceptance gates (founder-locked)

1. Principal understands DefendableOS in 90 seconds.
2. The site does not sound like generic AI SaaS.
3. The app shows trust · NOT vanity metrics.
4. Every dashboard dial maps to vocabulary AND receipts.
5. A sample assignment can be routed · scored · receipted · AND deeded.
6. The build preserves founder language.

Any artifact failing ANY of these does not ship to a board.

## What changes between operator and board language

| Element | Operator | Board |
|---|---|---|
| Math depth | Full breakdown | Headlines + appendix |
| Receipts | Inline | Footnoted with hashes |
| Voice | First-person operator | Principal-grade · still first-person |
| Sign-off | "To the shed" | Same |

The voice does not flatten for the board. The board reads the same voice the operator hears on a Friday afternoon principal call.
