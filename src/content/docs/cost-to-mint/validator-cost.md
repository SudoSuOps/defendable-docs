---
title: Validator Cost
description: Per-validator-pass cost. Deterministic Python validators vs model-backed validators.
---

Deterministic Python validators: ~$0.0001/pass (compute-bound on owned GPU). Model-backed validators (e.g., advisory content-validity): $0.0005/pass. Average across 12-check chain: $0.0002/pass.
