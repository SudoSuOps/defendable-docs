title: Deeds API
description: GET deeds · verify by hash · verify by slug. Search and pagination.

GET /v1/deeds/{deed_id} → fetch one. GET /v1/deeds/verify?hash={sha256} → verify by hash. LIST /v1/deeds?class=DDEED-VOCAB&category=cre_terms → filter by class + category.
