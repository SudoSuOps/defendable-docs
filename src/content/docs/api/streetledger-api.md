title: StreetLedger API
description: Browse · search · export ledger artifacts.

GET /v1/ledger/manifest → current manifest with root hash. GET /v1/ledger/terms → vocabulary terms (paginated). GET /v1/ledger/deeds/{class} → deeds by class. Standard JSON API · same data as the public surface.
