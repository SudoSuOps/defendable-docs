title: StreetChat API
description: Sessions · transcripts · pairs · ledger export. Phase 2 server mode.

POST /v1/chat/sessions → register session. GET /v1/chat/sessions/{id} → full session JSON. GET /v1/chat/sessions/{id}/pairs → per-session pair list. Phase 2 (server mode): real-time transcription streaming via WebSocket.
