Worked examples of the artifacts in the Defendable ecosystem. Some are **live** — minted today by [DefendableCloud](/defendablecloud/overview/) at `api.defendablecloud.com`. Others are **roadmap** shapes — illustrative JSON for surfaces that are specced but not deployed.

## Pages with concrete JSON

- [Sample Receipt](/examples/sample-receipt/) — a live `defendablecloud.eval-receipt/v1` from the Agent Work eval lane. **LIVE.**
- [Sample Verdict](/examples/sample-tribunal-verdict/) — a real `defendablecloud.verdict/v1` + the findings array emitted by the referee. **LIVE.**
- [Sample Deed](/examples/sample-deed/) — a `DDEED_VOCABULARY_TERM` for Defend-A-Pedia / DefendableLedger. **Roadmap shape.**
- [Sample Street Pair](/examples/sample-street-pair/) — a proposed Communicator pair. **Roadmap shape.**

## Text-only / stub-grade pages

- [Sample Street Event](/examples/sample-street-event/) — StreetChat event shape. **Roadmap shape.**
- [Sample Flight Sheet](/examples/sample-flight-sheet/) — a live DefendableCloud eval Flight Sheet (the rulebook). **LIVE** product primitive.
- [Sample Board Report](/examples/sample-board-report/) — operator/brand material from a listing engagement.

:::note[What is live vs. roadmap]
**LIVE today** (minted by `api.defendablecloud.com`, hash-chained per org): the **eval receipt** and the **verdict** it carries. The receipt is the only artifact below with a real per-org hash chain behind it.

**Roadmap** (specced, not a deployed API): the **deed / DDEED** (Defend-A-Pedia · DefendableLedger), the **street event** (StreetChat), and the **street pair** (Communicator). The JSON on those pages is the proposed shape, not output from a running endpoint.
:::
