:::note[Roadmap]
The Communicator is a planned meaning-layer rail (Rail 2) · it is **not yet built or deployed**. What is live today is DefendableCloud at `api.defendablecloud.com`: the Defendable Run primitive, the eval flight-sheet lane, and per-org hash-chained receipts. This page documents the design intent for the meaning layer · not a shipped feature.
:::

The Communicator is designed to sit BEFORE and AFTER the Tribunal · a bookend translator. Intake side: human utterance → structured directive. Output side: machine result → human-readable explanation. The intent is to train it on Defend-A-Pedia canon + StreetChat pairs (StreetChat is itself roadmap).

It is NOT a chatbot. It is a bidirectional translator between operator street talk and the structured directives the rest of the stack already understands.
