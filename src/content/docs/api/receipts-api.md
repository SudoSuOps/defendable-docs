---
title: Receipts API
description: POST · GET · LIST receipts. Pagination · filtering · streaming.
---

POST /v1/receipts → write a new receipt. GET /v1/receipts/{id} → fetch one. LIST /v1/receipts?ens=...&class=... → filter. Supports streaming via Server-Sent Events for high-throughput operators.
