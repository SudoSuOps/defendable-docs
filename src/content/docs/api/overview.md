The current production-facing API is the DefendableCloud API.

Start with [DefendableCloud API Surface](/defendablecloud/api/). It documents the current FastAPI route set for:

- auth and magic links
- organizations, roles, invites, API keys
- projects and Runs
- evidence uploads and submissions
- flight sheets, audits, checks, findings, verdicts
- approvals and receipts
- public receipt and ledger verification
- dataset library and download grants
- model catalog and model pin receipts
- cooks and runners
- incidents and stack assessment
- membership, admin, and internal staging

:::caution[Legacy API Pages]
The pages in this API section include older ecosystem rails such as DDEED, StreetLedger, StreetChat, Router, and Tribunal. Treat them as ecosystem context unless a DefendableCloud page explicitly links to them as current implementation.
:::
